# STV Market Researcher

Финальный вариант v2: строгий шрифтовой знак в стиле крупной финансовой группы.
Крупные STV с засечками, подпись MARKET RESEARCHER, платиновая разделительная линия.

- `../../../app/web/static/brand/stv-logo-v2.png` — логотип с прозрачностью для сайта.
- `stv-logo-light-v2.png` — логотип на светлом фоне для презентаций и публикаций.
- `../../../app/web/static/brand/stv-bot-avatar-v2.png` — квадратный аватар бота с запасом под круглое кадрирование.
- `../../../app/web/static/favicon.svg` — упрощённая типографическая иконка STV для небольших размеров.
- `imagegen-prompts.txt` — запросы для встроенного image_gen.

Цвета: midnight navy `#101D32`, platinum `#E6E7EB`, gray `#9A9FA9`.
На тёмном сайте используется светлая версия знака через CSS-фильтр.
Снимки уведомлений содержат логотип и полное название, включая автономный рендер без сети.
Обновлена версия кэша снимков H1, чтобы новые изображения не подменялись старым брендом.

Аватар подготовлен для загрузки в профиль Telegram-бота; внешний профиль этой задачей не изменён.
