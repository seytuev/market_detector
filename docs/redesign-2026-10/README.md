# LevelFrame — пакет редизайна, 10 октября 2026

Откройте `prototype.html` в браузере. Автономный макет работает без интернета и не обращается к API. Навигация, режимы анализа, темы, поиск, фильтры, инспектор, проверка и формы демонстрируют предполагаемое поведение. Все данные — демонстрационные, включая свечи; они не предназначены для анализа рынка.

## Передача другому ИИ

1. Передайте всю папку или архив `LevelFrame-design-handoff.zip`.
2. Начните с `IMPLEMENTATION_PROMPT_RU.md`.
3. Основной контракт: `SPEC_RU.md`; полный реестр существующих контролов и API: `FUNCTIONAL_INVENTORY.md`.
4. `prototype.html`, `prototype.css`, `prototype.js` — визуальный эталон и демонстрация взаимодействий, не готовый production-клиент.
5. `screenshots/` — контрольные изображения; `verification.json` — результаты автоматической проверки макета.

Изменения ограничены новым дизайн-пакетом. Исходные экраны, движок, база и API не изменены. Более ранняя концепция в `docs/rebrand` сохранена отдельно. Текущий пакет опирается на десять приложенных скриншотов и исходники `app/web`.
