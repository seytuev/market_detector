# Проверка дизайн-пакета

Проверяется автономный макет, а не работа backend и не полнота внедрения редизайна в продукт.

## Автоматическая проверка

- Chromium / Puppeteer, локальные файлы, без подключения API.
- 12 экранных состояний: обзор, HTF, H1, проверка, журнал, состояние контекста, лента, календарь, правила, настройки уведомлений, скринер, детали сетапа.
- Ширины 360, 390, 768, 1024, 1440, 1920 px; dark и light; всего 144 комбинации.
- Отсутствие горизонтального выхода `body` за viewport; таблицы могут прокручиваться локально.
- 11 проверок: переход к активу, HTF/H1, открытие слоёв, dialog/Escape, ошибка границ, результат проверки, три вкладки контекста, поиск, выбор сетапа, dirty/save, смена темы.
- Итог и геометрия каждого состояния — `verification.json`. Повторный запуск: `node docs/redesign-2026-10/verify.cjs` из корня репозитория при установленных `tools/node_modules` и Chrome по пути в скрипте.

## Визуальный просмотр

Проверены изображения desktop обзора и рабочего места, а также mobile рабочего места. Исправлены слишком мелкие SVG-подписи: шкала, названия зон и даты вынесены в независимый текстовый слой. В мобильной навигации доступ к настройкам сохранён в прокручиваемой ленте. Все PNG лежат в `screenshots/`.

## Ограничения

Не выполнены: полная WCAG-проверка, screen-reader тест, реальные API/WS-сценарии, профилирование production и regression tests движка, поскольку продуктовые исходники не менялись. Touch targets в production должны удовлетворять ТЗ; макет не заявляется соответствующим WCAG целиком. Серверные функции, слои и расширенные фильтры представлены частично; обязательное сохранение описано в SPEC и реестре.

`LevelFrame-mockup.html` — однофайловая версия для передачи. Генерация: `node docs/redesign-2026-10/package.cjs`. Исходники макета остаются отдельно для удобства реализации.
