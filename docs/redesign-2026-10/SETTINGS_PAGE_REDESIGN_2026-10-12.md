# Редизайн страницы «Настройки» — план и макет (2026-10-12)

## 1. Что найдено при аудите

Текущая страница: `index.html` → `#view-settings`, рендер `app.js` (SETTINGS_META,
openSettings), стили `style.css` (блок «Настройки» + блок 2721+).

## 2. Решение

1. **Настоящие вкладки**: видна только активная панель (`display:none` → `.is-active{display:block}`),
   переключение мгновенное, `?section=` сохраняется. Убрать scrollIntoView.
2. **Полные русские описания** для всех 48 ключей (META дополняется), чистка описаний
   от пустых скобок и двойных пробелов.
3. **Группировка «Правил анализа»** в подразделы с заголовками: Поиск зон (HTF) /
   Касания и глубина / LTF-наблюдения (H1) / HTF-контекст для LTF / Свежесть данных /
   Служебное. Экспериментальные (8 uncalibrated) — отдельный сворачиваемый блок.
4. **Умные контролы** по схеме из бэкенда:
   - CSV-перечисления → чипсы-чекбоксы (значение — скрытый input `data-key`, порядок как в списке опций);
   - ключи с выбором (`ltf_range_anchor_policy`, `htf_context_leg_anchor`) → селект с русскими подписями;
   - булевы → переключатель-свитч;
   - числа → `type=number` с границами из `_NUMERIC_RANGES` и подсказкой диапазона;
   - доли → живая подсказка «= N %».
   Бэкенд: `GET /api/settings` отдаёт `schema: {ranges, enums}` (`config.detector_field_schema()`).
5. **Активы**: точка статуса + свитч; счётчик «N из M включено»; подтверждение при выключении сохраняется;
   откат свитча при отмене/ошибке.
6. **Оформление**: три карточки тем в один ряд с превью-свотчем.
7. **Футер**: «Сохранить» disabled без правок; «Отменить» → «Сбросить» (откатывает поля,
   виден только при правках); добавлена «Закрыть» (уход на «Обзор», с подтверждением при правках).
   После сохранения settingsOriginal обновляется из ответа.

Не трогаем: серверную валидацию (L04), пересчёт, LTF-модалку на /ltf.html, авторизацию.

## 4. Приёмка

- Каждая вкладка показывает ровно одну панель; URL ?section= синхронизируется.
- Ни одного сырого ключа в интерфейсе; пустых «()» в описаниях нет.
- Чипсы/селекты/свитчи сохраняют прежний контракт POST (только изменённые поля).
- Сброс/закрытие/сохранение и disabled-состояния соответствуют dirty-состоянию.
- Тёмная и светлая темы, мобильная ширина (≥360px) — без поломок.
