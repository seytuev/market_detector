# Долгоживущие HTF-идеи

HTF-идея (`htf_idea`, версия `htf-ideas-1`) сохраняет происхождение зон
после отмены отдельной LTF-попытки. Источник — подтверждённый HTF-контекст,
BOS/SMS, причинные движения и сохранённые связи Entry Zones. Цена сама по
себе не является доказательством связи. Старые версии диапазона сохраняют
принадлежность зон; для входа проверяется текущая доступная версия.

Состояния: `waiting_zones`, `active`, `paused_data`, `closed`.
Причины закрытия: `parent_invalid`, `zones_exhausted`, `manual`.
Обратный слом завершает попытку входа, но не идею. Давность не закрывает
наблюдение с живой идеей. Проверенная идея восстанавливает наблюдение,
которое раньше было закрыто только по давности.

## Обработка и восстановление

После обработки H1 и replay вызывается `reconcile_ideas`. Он восстанавливает
актуальность всех сохранённых H1-зон по закрытым свечам, включая зоны
отменённых попыток и зоны вне текущего Premium/Discount. Полное перекрытие,
снятие/пробой уровня и порог повторного использования проверяются общей
функцией `relevance_reason`. Разрыв цены через дальнюю границу тоже потребляет
зону. Начальный импульс формирования не считается повторным тестом.

Пересчёт повторяемый, без отправки исторических сигналов. Версия сохраняется
в `htf_ideas:version:<instrument_id>`. Ручное закрытие хранится отдельно и
не снимается пересчётом. Пропуски истории дают `data_gap`; они не позволяют
объявить нетронутую зону актуальной или закрыть идею только из-за отсутствия
данных. Проекция графика ничего не записывает и не использует будущие свечи.

## Интерфейс

Ответ `/api/ltf/instruments/{id}/structure` дополнен `htf_ideas`.
В `detected_zones` добавлены `relevance` (актуальность, причина, качество
истории, время исключения) и `idea_links` (идея, родитель, направление,
исходный слом, `eligible_now`, причина отсутствия готовности).
`current_scenario` и старый `scenario_admission` сохранены для совместимости.

Фильтр «Актуальные зоны HTF-сценариев» объединяет обе стороны. Выбор конкретной
идеи ограничивает это объединение. История показывает завершённые зоны;
список под основным графиком использует тот же отбор. Готовность входа
отображается отдельно и не определяет видимость актуальной зоны.

`POST /api/ltf/ideas/{id}/close` требует авторизации владельца, закрывает идею
и её текущую попытку входа. HTF-родитель при этом не изменяется.

## SSL/BSL D1/W1

В `zone.evidence` сохраняются `extreme_at`, `extreme_timeframe=H1`,
`extreme_anchor_quality` и `group_extreme_at`. `display_from` указывает на
первую H1-свечу с экстремумом исходной HTF-свечи. При неполной истории
используется прежнее начало HTF-свечи, качество — `incomplete`.
Для группы берётся участник, задающий цену группы, при равенстве — первый.
`formed_at`, `confirmed_at`, цены и правила распознавания не меняются.
Якоря уточняются при обнаружении HTF-уровней и после загрузки/обработки H1.
