# Отчёт: редизайн LevelFrame, 10.10.2026

Основа — светлая тема. Тёмная и «как в системе» остаются явным выбором и пишутся в `lf:theme`. Если ключа нет, открывается светлая тема, системная схема не подхватывается.

Бэкенд, схема БД, формулы, пороги, causal timestamps, UTC/МСК на сервере и Lightweight Charts 4.2 не менялись. Синтетические свечи и счётчики макета к API не подключались. Публикации и деплоя нет.

Карта контролов: `docs/redesign-2026-10/FUNCTION_MAP.md`.

## Что изменилось

Статика, без перезапуска процесса:

| Файл | Смысл |
|---|---|
| `index.html`, `events.html`, `alt.html`, `ltf.html` | Общий shell: боковая навигация, крошка, часы МСК, нижняя лента из четырёх входов и «Ещё» |
| `style.css` | Токены светлой темы на `:root`, тёмной на `[data-theme="dark"]`, сетка разделов и брейкпоинты |
| `common.js` | Тема по умолчанию — светлая; часы; панель «Ещё» |
| `app.js` | Крошка, режим графика, свёртка списка активов, прокрутка к разделу настроек |
| `now.js` | Счётчики-кнопки, выбор строки отдельно от открытия, последние записи журнала, пустые состояния |
| `journal.js` | Фильтр загруженного окна, группы по 60 с, удержание новых записей при прокрутке |
| `events.js` | Словарь правил, доля лонгов в процентах и исходная дробь, сетка одного UTC-дня |
| `favicon.svg` | Знак рамки |

Навигация: Обзор `#now`, Рабочее место `#desk` (алиас `#overview`), Проверка `#review`, Скринер `/alt.html`, Журнал `#journal` (алиас `#events`), Контекст рынка `/events.html`, Настройки внизу sidebar. H1 — режим рабочего места `?mode=h1#desk`, не пункт глобального меню. `/ltf.html` без `stay=1` по-прежнему уходит на рабочее место.

Слои OB, FVG, BSL и SSL остаются отдельными флажками. Группы в меню слоёв — только подписи.

## Проверки

Браузер, уже запущенный сервер `http://127.0.0.1:8000`, живые ответы API. Горизонтального overflow документа не было на Обзоре, рабочем месте, проверке, журнале, настройках, контексте и скринере при 360, 390, 768, 1024, 1440 и 1920 px.

Отдельно проверено:

- Без `lf:theme` корень получает `data-theme="light"`. После `HTF.theme.set('dark')` и перезагрузки тёмная тема держится на 390 и 1440. Возврат на светлую срабатывает.
- На 1440 и 1920 кнопка «Активы» у графика скрыта, список активов виден. Ниже 1280 кнопка видна, список свёрнут.
- Ниже 1024 рабочее место — одна колонка, график сверху. На 768 высота графика 410 px. На 390 высота 340 px, график выше карточки «События и время».
- На 360 и 390 три счётчика Обзора стоят в ряд, пояснение под числом скрыто, таблица активов начинается на первом экране.
- Кнопка «На проверку» открывает `#review` и не меняет статусы. «Выбрать» выделяет одну строку. Название актива открывает рабочее место. «Ещё» открывается и закрывается по Escape.
- Журнал: строка, которой нет среди загруженных, даёт «По фильтру среди загруженных записей ничего нет.» Очистка поля возвращает список.
- Контекст рынка: лента, календарь и правила переключаются, `aria-pressed` встаёт на выбранный режим. Календарь — сетка месяца с одним отмеченным UTC-днём.
- Панель «Отменить / Сохранить» стоит под прокруткой разделов и не лежит поверх следующего поля.

`pytest tests/test_web.py tests/test_alt_api.py tests/test_alt_range_editor.py tests/test_data_freshness.py`: 62 passed. Это решения проверки, настройки, превью и конфликт ревизии диапазона, свежесть данных. Повторно не нажимались «Выключить», «Запустить сверку» и клавиши решений проверки: это живая очередь.

Снимки сверки лежат локально в `docs/redesign-2026-10/check/` и в коммит не входят.

## Сохранённые функции

Соответствие контролов API — в `FUNCTION_MAP.md`. Кратко: обзор читает `/api/ltf/instruments` и кандидатов; рабочее место — свечи, зоны, структуру H1 и прежние POST/PATCH зоны; проверка — семь решений и выгрузку; журнал — `GET /api/journal`; настройки — `GET/POST /api/settings` и прежний адаптер процентов; контекст — `/api/events/*`; скринер — прежние id `alt.js` / `alt_chart.js`. Два HYPE не сливаются. Тексты бота «Сейчас» не менялись. Уведомления выключенного актива не открывались этим редизайном.

## Ограничения

- Фильтр журнала по активу, датам и тексту действует на уже загруженные `limit=100` записей. Отдельного серверного поиска и постраничности нет. Подпись на экране это говорит.
- Группа журнала — только показ: соседние строки с тем же смыслом и не дальше 60 с. Разные исходы не склеиваются. Записи в базе не удаляются.
- Календарь контекста — проекция одного `utc_date` из ответа, не список дней и не экономический календарь. `empty_reason` не подменяется цепочкой.
- Страница контекста не открывает WebSocket. Точка соединения остаётся на Обзоре, рабочем месте, скринере и странице LTF.
- Разделы настроек — один свиток. Кнопки прокручивают к разделу и пишут `?section=` только по клику. Скрытых панелей нет: поля, тема и пересчёт остаются в документе.
- На рабочем месте высотой около 900 px правая колонка делит место между карточкой сценария и списком зон. Список зон начинается у нижнего края и листается внутри колонки.
- Контраст не мерился отдельным инструментом. Полный проход проверки только с клавиатуры по живой очереди не делался, чтобы не записать решение.
- Редизайн не закоммичен и не отправлен на origin.
